# C++: From Fundamentals to Object-Oriented Programming

Source code for the book **C++: From Fundamentals to Object-Oriented Programming** by Samran Naveed.

Each chapter folder (`ch01` to `ch33`) contains the solutions to the Practice Programs at the end of that chapter. Folders `ch03` to `ch33` also contain `more-exercises.md`, with extra Determine the output and Find the error exercises that continue the Exercises section of the book.

## How to use

1. Try every Practice Program yourself first. Look at a solution only after you have written and tested your own.
2. All programs are standard C++17. In Dev-C++, switch on C++17 as shown in Appendix A of the book (Tools > Compiler Options, add `-std=c++17`).
3. Open a `.cpp` file, compile and run it (F11 in Dev-C++). Programs made of several files must be built as a project (Appendix A, Section A.5).

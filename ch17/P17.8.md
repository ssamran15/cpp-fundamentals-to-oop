# P17.8: Attributes and behaviours (design exercise)

**Problem:** (Design exercise, no code) For each of these objects, list at least four attributes and four behaviours, and say which attributes should be private: a mobile phone, a library book, an ATM, a cricket player.

There is no single correct answer. These are sample answers. In practice almost every attribute is kept private and is reached only through the behaviours (public functions); the notes say why the private ones matter most.

## Mobile phone

| Attributes | Behaviours |
|---|---|
| model | makeCall() |
| phone number | sendMessage() |
| battery level | charge() |
| PIN / lock code | lock() / unlock() |
| contacts list | addContact() |
| volume | changeVolume() |

**Private:** all of them. The PIN must never be readable from outside; `unlock()` only checks a PIN given to it. The battery level should change only through `charge()` and use, never by direct assignment.

## Library book

| Attributes | Behaviours |
|---|---|
| ISBN | issue() |
| title | returnBook() |
| author | renew() |
| issued or available | isAvailable() |
| due date | calculateFine() |
| borrower's card number | show() |

**Private:** all of them, especially the issued status, due date and borrower. If these could be changed directly, a book could be marked "available" while a student still has it.

## ATM

| Attributes | Behaviours |
|---|---|
| machine ID | insertCard() |
| location | checkPin() |
| cash available | withdraw() |
| current card / account | showBalance() |
| wrong PIN attempts | printReceipt() |
| out of service or working | ejectCard() |

**Private:** all of them. The cash available must change only through `withdraw()`, which checks the balance and the cash in the machine. The count of wrong PIN attempts must not be resettable from outside.

## Cricket player

| Attributes | Behaviours |
|---|---|
| name | bat() |
| shirt number | bowl() |
| role (batter, bowler, all-rounder) | field() |
| matches played | addRuns() |
| total runs | addWickets() |
| wickets taken | battingAverage() |

**Private:** the statistics (matches, runs, wickets). They should change only through `addRuns()` and `addWickets()`, which can reject negative values. The name and role can also be private with a `get` function for each.
